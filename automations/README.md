# Your automations

One folder per automation, each with an `automation.yaml`. Everything here except this README is git-ignored, because it holds your paths and repo names.

- Start with `uv run flowhaus scan` and `uv run flowhaus add ...` (see AGENTS.md), or copy a folder from `examples/automations/`.
- Reference: docs/automations.md
- Check: `uv run flowhaus check`
